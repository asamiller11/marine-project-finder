Put hand-saved notices here (PDF, HTML or text), then run:  python -m mpf ingest --source drop_folder

Optional: add a YAML file named like the notice plus ".yaml" with facts the file does not show:

  url: https://...
  title: ...
  province: Quebec
  proponent: ...
  comment_deadline: 2026-11-30
  decision_date:
  stage: public comment open

Anything you leave out is shown as "unknown".
